# Festulentus — Animation Studio

A single-file, self-contained portfolio site for **Festulentus**, a multidisciplinary
animation studio working across every tier of the craft — from logo stings to fully
simulated CG cinematics.

## What's inside
- `index.html` — the site. All CSS, JavaScript, **and fonts are inlined** (base64);
  no build step and no external dependencies.
- `assets/skills/` — free-licensed stock media (video + stills) for the "What we do"
  tiles. Videos lazy-load and only play while scrolled into view.

## Features
- Chromatic-aberration "CHROMA" concept (RGB channel split motif)
- "What we do" — 12 animation disciplines with premium video/photo art per tile
- Capability Spectrum — a four-tier complexity ladder (Entry → Craft → Advanced → Complex)
- Custom cursor, scroll reveals, animated counters, magnetic buttons, grain overlay
- Contact form wired to FormSubmit (delivers to festulentus@gmail.com)
- Fully responsive, respects `prefers-reduced-motion`
